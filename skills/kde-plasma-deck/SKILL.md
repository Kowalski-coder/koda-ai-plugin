# Диагностика и управление KDE Plasma на Steam Deck

Руководство для Koda по восстановлению и настройке графической среды KDE Plasma в режиме рабочего стола Steam Deck, основанное строго на официальной документации ArchWiki (раздел KDE) и KDE UserBase.

> [!IMPORTANT]
> **ПРАВИЛО ПРИВИЛЕГИЙ ROOT:**
> Любые команды, требующие прав суперпользователя (root/sudo), ОБЯЗАТЕЛЬНО выполнять через `pkexec <команда>` вместо `sudo <команда>`, чтобы пользователю выводилось графическое окно ввода пароля.

## 1. Диагностика и сброс конфигурации дисплеев (KScreen)

При подключении или отключении внешних мониторов, док-станций или телевизоров экран может оставаться чёрным или выставлять неподдерживаемое разрешение.

### 1.1 Диагностика через kscreen-doctor (Wayland / Plasma CLI)
Официальная утилита командной строки KDE для проверки состояния подключённых дисплеев:
```bash
kscreen-doctor --outputs
```
Показывает список всех видеовыходов (eDP-1, DP-1, HDMI-A-1), их статус (enabled/disabled), поддерживаемые режимы, частоту обновления и текущий режим.

### 1.2 Сброс сохранённых конфигураций экранов
Согласно официальной документации ArchWiki, некорректно сохранённые настройки экранов сбрасываются очисткой кэша KScreen:
```bash
rm -rf ~/.local/share/kscreen/*
```
После очистки перезапустите службу управления дисплеями:
```bash
systemctl --user restart plasma-kscreen
```
При этом мониторы автоматически вернутся к безопасным стандартным разрешениям (Native EDID).

## 2. Перезапуск компонентов графической оболочки

### 2.1 Перезапуск панели и рабочего стола (Plasma Shell)
Если панель задач зависла, пропали виджеты или перестал отвечать рабочий стол:

*   **Через systemd (основной рекомендуемый метод в современных версиях Plasma):**
    ```bash
    systemctl --user restart plasma-plasmashell
    ```
*   **Через kquitapp (альтернативный метод):**
    ```bash
    kquitapp6 plasmashell || kquitapp5 plasmashell
    plasmashell >/dev/null 2>&1 &
    ```

### 2.2 Перезапуск или переконфигурация композитора KWin
Для повторной инициализации настроек оконного менеджера без выхода из сессии:
```bash
qdbus org.kde.KWin /KWin reconfigure
```

## 3. Ярлыки рабочего стола и системная база приложений

### 3.1 Ярлыки на рабочем столе
* Ярлыки хранятся в каталоге `~/Desktop/`.
* Чтобы файл `.desktop` запускался по клику в KDE, он обязан иметь права на исполнение:
  ```bash
  chmod +x ~/Desktop/*.desktop
  ```

### 3.2 Обновление кэша приложений и типов файлов
Если установленное приложение или ярлык не отображается в меню запуска KDE:
```bash
update-desktop-database ~/.local/share/applications/
kbuildsycoca6 --noincremental 2>/dev/null || kbuildsycoca5 --noincremental 2>/dev/null
```
